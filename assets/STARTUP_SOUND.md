# zevMobile startup sound

Add the finished sound as `assets/startup.wav`.

Recommended FL Studio export:
- WAV
- PCM / uncompressed
- 16-bit
- 44.1 kHz
- Mono for a tiny phone-style sound, or stereo if desired
- About 0.5–2 seconds
- Do not use MP3 compression

44.1 kHz / 16-bit PCM WAV is a safe default for the Windows emulator.
